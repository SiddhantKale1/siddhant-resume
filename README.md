## 🛠️ Tech Stack & Architecture

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Radix UI primitives + Lucide Icons
- **Design Tokens**: Precision Dark Obsidian theme (`#0B0D11` base, `#00E599` Terminal Emerald accent)
- **Deployment & Builds**: Fast incremental builds via Vite (~2s production build)

## 🚀 Local Development

```bash
# Clone the repository
git clone git@github.com:SiddhantKale1/siddhant-resume.git
cd siddhant-resume

# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build
```
