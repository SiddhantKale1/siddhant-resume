## ⚡ Featured Projects Highlighted

1. **Sentinel – Autonomous SIEM & Security Telemetry Platform**
   - Engineered an autonomous SIEM platform with a compiled Golang backend core delivering **12,480+ EPS** sustained throughput and **27µs** sub-millisecond log event parsing execution.
   - Built cross-platform telemetry agents (Go & Python) collecting system audit logs and enforcing automated zero-trust host isolation via kernel firewall rules (`iptables`).
   - Designed real-time SOC command dashboard using React, TypeScript, and WebSockets with MITRE ATT&CK threat correlation.
   - [Repository](https://github.com/SiddhantKale1/SIEM-Dashboard-security-information-event-mangement-)

2. **Cognivex – Intelligent RAG Machine Troubleshooting System**
   - Architected a domain-specific Retrieval-Augmented Generation (RAG) platform to query dense technical machine manuals with zero hallucination.
   - Automated ingestion pipeline using PyMuPDF and LangChain text splitters, preserving page boundaries and error code metadata.
   - Indexed dense vector embeddings in Qdrant Vector DB via `BAAI/bge-base-en-v1.5`, enabling sub-second cosine similarity retrieval.

3. **Brain Tumor Detection System with Grad-CAM**
   - Trained a deep learning Convolutional Neural Network (CNN) on MRI scans, implementing Grad-CAM heatmaps for explainable diagnostic localization.
   - OpenCV image preprocessing pipeline implementing skull-stripping, contrast enhancement (CLAHE), and data augmentation.
   - Deployed real-time inference web services with FastAPI & Flask.
   - [Repository](https://github.com/SiddhantKale1/Brain-Tumor-Detection)

4. **Riders United – Tactical Convoy GPS & Voice Comms Platform**
   - Real-time motorcycle convoy tracking system with WebSockets synchronizing live GPS positions, heading angles, and speeds.
   - Low-latency WebRTC Push-To-Talk (PTT) walkie-talkie audio comms with authentic radio acoustics and 1-tap hazard broadcasts.

5. **Split It – Group Expense Management Platform**
   - Splitwise-inspired expense platform built with Flask and MySQL featuring clean MVC patterns, session authentication, and transactional integrity.
   - Exact simplified balance optimization algorithm to minimize the net number of financial settlement transactions required across groups.
   - [Repository](https://github.com/SiddhantKale1/Split_It)
